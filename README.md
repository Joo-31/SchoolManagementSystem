# School Management System

A comprehensive School Management System built with **.NET 8** using **Clean Architecture** and **SOLID Principles**.

## 🛠️ Tech Stack

- **.NET 8** (C#)
- **ASP.NET Core Web API**
- **Entity Framework Core 8** (SQL Server)
- **JWT Authentication** (with Roles)
- **AutoMapper** (DTOs)
- **Serilog** (Logging)
- **FluentAssertions** + **Moq** + **xUnit** (Testing)
- **Docker** + **Docker Compose**

## ✨ Features

- 🔐 **JWT Authentication** with Roles (Admin, Teacher, Student)
- 📚 **Full CRUD** for Students, Teachers, Courses, Classes, Grades, Attendance
- 🔍 **Search & Filter** endpoints
- 📊 **Statistics** endpoints
- 📄 **Pagination** support
- 🎯 **Global Error Handling** (Middleware)
- 📝 **Logging** with Serilog (Console + File)
- 🧪 **Unit Tests** (xUnit + Moq)
- 🐳 **Docker** support
